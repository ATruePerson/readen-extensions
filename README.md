# Readen Extensions

Extension repo for the Readen manga reader. Sources are written in the
**Paperback 0.8 format** (`SourceInfo` + `Source` on `@paperback/types`), so
every extension here also loads in the Paperback app — and any Paperback
0.8 extension can load in Readen once the app shell exists.

The app ships empty: users add repo URLs, install sources, then browse and
read. Readen hosts no content.

## Layout

- `src/Nhentai/` — reference source for nhentai.to (`Nhentai.ts`,
  `Parser.ts`, `Nhentai.test.ts`, `includes/icon.png`).
- `bundles/` — generated by `npm run bundle`; host it (GitHub Pages,
  Cloudflare Pages) and add the URL in-app as a repo.

## Commands

```sh
npm test     # unit tests (Node 20+, no build step)
npm run bundle  # esbuild bundle + versioning.json + repo homepage
npm run serve   # local test server for on-device testing
```

## Add a source

1. Create `src/<Name>/<Name>.ts` exporting `<Name>Info: SourceInfo`,
   `<Name> extends Source`, and `Sources = { <Name>Info }`.
2. Put its icon at `src/<Name>/includes/icon.png`.
3. Add `src/<Name>/<Name>.test.ts` and run `npm test`.
4. Run `npm run bundle` and publish `bundles/`.
